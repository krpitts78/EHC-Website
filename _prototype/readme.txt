Executive Hunting Club Website
==============================

Quick start
-----------
1. View the prototype: double-click prototype.html — opens in your default browser.
   No build step, no install. Uses React + Tailwind + lucide via CDN.

2. Easter eggs to try:
   - Type "texas" anywhere → "HOOK 'EM!" flash
   - Triple-click the sidebar logo → Longhorn badge next to member name
   - Tiny 🤘 in the public footer next to the charter number
